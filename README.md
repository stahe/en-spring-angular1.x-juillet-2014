## 📌 Overview

This document provides a joint introduction to two major frameworks through the implementation of a **client/server** application:

* **AngularJS 1.x** for the client-side (frontend)
* **Spring 4** for the server-side (backend)

For simplicity, the terms **Angular** and **Spring** will be used throughout the rest of this document.

The goal is to provide a concrete illustration of the interactions between a web client and a Java server using technologies widely used in modern web application development.

---

## 🎯 Objectives

* Understand client/server architecture
* Implement AngularJS 1.x for frontend development
* Use Spring 4 to expose backend services
* Illustrate HTTP exchanges between client and server
* Manipulate a database via JPA

---

## ⚙️ Prerequisites

Understanding this document requires the following knowledge:

* Intermediate level in **Java EE**
* Proficiency in **JPA (Java Persistence API)**
* Knowledge of a previous version of **Spring**
* Use of **Maven** for project management
* Understanding of **HTTP** communication
* Basics in:
  * **HTML**
  * **JavaScript**

Additional concepts are introduced gradually throughout the case study.
